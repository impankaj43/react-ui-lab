# 🔍Debounce-Based Searchable Dropdown

🔗 **Repo**: [`react-ui-lab`](https://github.com/impankaj43/react-ui-lab)  
📁 Path: `react-ui-lab/03-debounce-searchable-dropdown`

This project demonstrates a searchable dropdown built using React that implements **Debounced Search** to optimize user input handling.
The component fetches user data from an API based on the search query, reducing unnecessary requests.
It also manages dropdown visibility and item selection smoothly, ensuring a clean, real-world user experience.

---

## ✅ Topics Covered

- 🔸 Controlled form handling in React
- 🔸 Controlled input handling in React
- 🔸 Searchable dropdown implementation
- 🔸 Debounced search using setTimeout
- 🔸 API-based data fetching on user input
- 🔸 Optimizing API calls to prevent unnecessary requests
- 🔸 Dropdown visibility and selection handling
- 🔸 Managing real-world edge cases in controlled components

## 🚀 How to Use This Project

You can **download only the `03-debounce-searchable-dropdown` folder** from the repo, or clone the full repo and navigate to this folder.

### ▶️ Steps to Run:

```bash
# Step 1: Navigate to the project folder
cd 03-debounce-searchable-dropdown

# Step 2: Install dependencies
npm install

# Step 3: Run the project
npm run dev

```
