# 📦 Offset-Based Pagination Products Page

🔗 **Repo**: [`react-machine-coding-practice`](https://github.com/impankaj43/react-machine-coding-practice)  
📁 Path: `react-machine-coding-practice/07-visulaized-list`

This section demonstrates a custom **Virtualized List (Windowing)** component. Unlike standard lists that render every single item at once—which can crash a browser when dealing with thousands of rows—this implementation only renders the items currently visible in the viewport.

---

## ✅ Topics Covered

- 🔸 List Virtualization / Windowing: Understanding the concept of rendering only what is visible.
- 🔸 Manual Scroll Management: Tracking scrollTop to calculate the current viewing window.
- 🔸 Efficient Coordinate Mapping: Using absolute positioning to place items at their correct spatial offsets ($index \times itemHeight$).
- 🔸 Performance Benchmarking: Minimizing browser reflows by keeping the DOM tree shallow.
  🔸 React State Synchronization: Managing UI updates efficiently during high-frequency scroll events.
