## 🚀 How to Use This Project

You can **download only the `08-progress-bar` folder** from the repo, or clone the full repo and navigate to this folder.

### ▶️ Steps to Run:

```bash

cd 08-progress-bar

# Step 2: Install dependencies
npm install

# Step 3: Run the project
npm run dev
```
