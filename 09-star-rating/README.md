# 📦 Offset-Based Pagination Products Page

🔗 **Repo**: [`react-ui-lab`](https://github.com/impankaj43/react-ui-lab)  
📁 Path: `react-ui-lab/09-start-rating`

A reusable **Star Rating** component built with React that allows users to select and preview ratings through interactive star icons. The project demonstrates React state management, event handling, dynamic rendering, component reusability, controlled component patterns, and user interaction handling through click, hover functionality.

---

## ✅ Topics Covered

- 🔸 useState
- 🔸 Controlled Components
- 🔸 Props & Component Reusability
- 🔸 Dynamic List Rendering
- 🔸 Event Handling (Click & Hover)
- 🔸 Conditional Rendering
- 🔸 State-Driven UI Updates
- 🔸 Dynamic Styling
- 🔸 Array Mapping
- 🔸 Parent-Child Communication
- 🔸 Reset Functionality
- 🔸 Interactive UI Patterns

---

## 🚀 How to Use This Project

You can **download only the `09-start-rating` folder** from the repo, or clone the full repo and navigate to this folder.

### ▶️ Steps to Run:

```bash
# Step 1: Navigate to the project folder
cd 09-start-rating

# Step 2: Install dependencies
npm install

# Step 3: Run the project
npm run dev

```
