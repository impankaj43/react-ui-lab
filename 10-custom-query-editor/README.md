# 📦 Offset-Based Pagination Products Page

🔗 **Repo**: [`react-ui-lab`](https://github.com/impankaj43/react-ui-lab)  
📁 Path: `react-ui-lab/10-custom-query-editor`

A dynamic **Custom Query Editor** inspired by enterprise search systems. Users can create logical query groups using AND/OR operators, build complex search expressions, manage multiple condition groups, and visualize the generated query structure in real time. Includes debounced keyword search, dynamic state management, reusable UI patterns, and JSON-based query generation.

- 🔸 useState

- 🔸 Conditional Rendering
- 🔸 Event Handling
- 🔸 Component Reusability
- 🔸 Query Builder Logic
- 🔸 AND / OR Operators

## 🚀 How to Use This Project

You can **download only the `10-custom-query-editor` folder** from the repo, or clone the full repo and navigate to this folder.

### ▶️ Steps to Run:

```bash
# Step 1: Navigate to the project folder
cd 10-custom-query-editor

# Step 2: Install dependencies
npm install

# Step 3: Run the project
npm run dev

```
