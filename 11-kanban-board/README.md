# 📦 Offset-Based Pagination Products Page

🔗 **Repo**: [`react-ui-lab`](https://github.com/impankaj43/react-ui-lab)  
📁 Path: `react-ui-lab/11-kanban-board`

A **Kanban Board** implementation built with React that allows users to manage tasks across multiple workflow stages using native HTML Drag and Drop APIs. Tasks can be moved between Todo, In Progress, and Done columns with state-driven UI updates and immutable state management.

---

## ✅ Topics Covered

- 🔸 Native HTML Drag and Drop API
- 🔸 Drag Events (onDragStart)
- 🔸 Drop Events (onDrop)
- 🔸 Drag Over Handling (onDragOver)
- 🔸 Task Movement Between Columns
- 🔸 Immutable State Updates
- 🔸 State-Driven UI Updates
- 🔸 Dynamic Column Rendering
- 🔸 Kanban Board Architecture

---

## 🚀 How to Use This Project

You can **download only the `11-kanban-board` folder** from the repo, or clone the full repo and navigate to this folder.

### ▶️ Steps to Run:

```bash
# Step 1: Navigate to the project folder
cd 11-kanban-board

# Step 2: Install dependencies
npm install

# Step 3: Run the project
npm run dev

```
